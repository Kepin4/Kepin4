## 👤 About

I'm a developer who started on the **full-stack** side and is now specializing in **frontend**.

Previously, I worked at an **ERP-based software house**, where I handled both system development and database structure design. That backend and data background still shapes how I build UIs today: I think about how data flows, how it's modeled, and what the screen needs from it before I write a component.

Today I focus on **React, React Native, and Next.js**, building interfaces that are fast, consistent, and pleasant to use. I care about design systems, color tokens, and the small interaction details that make an app feel finished.
